# 단계별 폰 확인 체크리스트

각 단계 완료 조건을 폰(QA APK)과 서버로 확인하는 순서다. 서버 실행·APK 설치는 [run-guide.md](run-guide.md).
서버 쪽 확인은 Swagger(`http://<IP>:8080/swagger`) 또는 아래 `curl` 로 한다. `TOKEN` 은 로그인 응답의 accessToken, `CID` 는 캐릭터 ID.

```bash
TOKEN=$(curl -s -X POST http://<IP>:8080/auth/login -H 'content-type: application/json' \
  -d '{"username":"<아이디>","password":"<비밀번호>"}' | python3 -c "import sys,json;print(json.load(sys.stdin)['accessToken'])")
H="-H 'Authorization: Bearer $TOKEN' -H 'X-Character-Id: <CID>'"
```

## 1단계 기반: 로그인

- [ ] APK 를 실행하면 `ASHVEIL` 로그인 화면이 나온다. 아래에 `서버: http://... (runtime|build|default)` 가 보인다.
- [ ] (QA) 서버 설정 버튼으로 Mac LAN IP 를 넣고 저장한다.
- [ ] 아이디·비밀번호를 넣고 **회원가입** → "계정을 만들었습니다" 후 캐릭터 선택 화면으로 넘어간다.
- [ ] 앱을 다시 켜고 같은 계정으로 **로그인** 이 된다. 틀린 비밀번호면 "아이디 또는 비밀번호가 올바르지 않습니다".

## 2단계 월드·플레이어

- [ ] **+ 새 캐릭터** → 이름·직업(전사/궁수/마법사)·성별 → 만들기. 같은 이름을 다른 계정에서 만들면 "이미 사용 중인 캐릭터 이름입니다".
- [ ] 캐릭터 4개째는 슬롯이 없어 만들 수 없다(서버도 `CHARACTER_LIMIT`).
- [ ] 게임 시작 → 마을(하늘빛 마을)에서 시작한다. 왼쪽 아래 조이스틱으로 걷는다. 오른쪽 위 미니맵에 점들이 보인다.
- [ ] 북쪽 정문으로 나가면 "초록 들판에 들어섰습니다" 토스트, 상단 구역 이름이 바뀐다. 더 북쪽은 "잿빛 숲", 길 끝 투기장은 "불꽃 군주의 폐허".
- [ ] **귀환** 버튼으로 마을로 돌아온다.
- [ ] 사냥터에서 **나가기** → 캐릭터 선택 → 다시 시작하면 마지막 위치에서 시작한다(위치는 5초마다 저장).

## 3단계 전투·재화

- [ ] 사냥터에서 몬스터를 탭하면 대상 정보(이름·HP)가 뜨고 자동으로 다가가 공격한다. **공격** 버튼은 가장 가까운 몬스터를 고른다.
- [ ] 몬스터가 다가와 공격한다. 너무 멀리 끌고 가면 원래 자리로 돌아가며 HP 를 회복한다.
- [ ] 처치하면 `+N 골드`, `+N 경험치` 가 뜨고 상단 골드가 오른다.
- [ ] **정보 → 골드 내역** 의 최신 잔액 = 상단 골드 = 서버 원장.
  ```bash
  eval curl -s http://<IP>:8080/currency/ledger?limit=5 $H      # balanceAfter 첫 값이 화면 골드와 같다
  ```
- [ ] **자동** 을 켜면 주변 몬스터를 찾아 싸우고, HP 50% 이하면 물약을 자동으로 마신다(물약 개수가 줄어든다).
- [ ] 죽으면 "사망했습니다" 창(경험치 손실 표시) → **마을에서 부활**.

## 4단계 인벤토리·상점·강화

- [ ] 마을 **상인 브릭** 을 탭 → 상점. 물약 10개 구매 → 골드 감소, 가방의 물약 수 증가.
- [ ] 골드가 부족한 상품을 사면 "골드가 부족합니다".
- [ ] **가방** → 장비 탭 → **장착/해제** → 정보 창 공격력·방어력이 바뀐다.
- [ ] 판매 탭에서 물약 판매 → 골드 증가. 장착 중인 장비는 목록에 없다.
- [ ] **대장장이 오른** → 강화. 무기 강화 주문서(상점 500골드)로 짧은 검을 +3 까지 올리면 매번 성공한다.
- [ ] (QA) GM 콘솔 → 강화 확률 `4 / 0 / 0 / 1` 적용 → +4 시도 → "장비가 파괴되었습니다!", 가방에서 사라진다. `4 / 0 / 1 / 0` 이면 "강화 실패". 초기화로 되돌린다.
- [ ] 결과마다 서버 인벤토리와 화면이 같다.
  ```bash
  eval curl -s http://<IP>:8080/characters/<CID>/inventory $H
  ```

## 5단계 봇

- [ ] 사냥터에 이름 위에 `Lv.N 이름` 이 뜬 캐릭터(봇)들이 돌아다니며 몬스터를 잡는다. 파란 이름이 선량.
- [ ] 선공형 봇은 가까이 가면 먼저 공격한다. 평화형 봇은 때리면 도망간다.
- [ ] **PK** 를 켜고 봇을 처치하면 일정 확률(기본 50%)로 그 봇의 아이템을 얻는다("…에게서 …을(를) 얻었습니다").
- [ ] (QA) GM 콘솔 드랍 확률 `1 / 1 / 1` 적용 후 봇을 처치하면 항상 아이템을 얻는다.
- [ ] 처치한 봇은 60초 뒤 다시 나타난다.
  ```bash
  eval curl -s "http://<IP>:8080/bots?zone=Beginner" $H     # isDead, respawnAt, itemCount 확인
  ```

## 5-1단계 PK

- [ ] PK 모드에서 선량한(파란) 봇을 먼저 때리면 내 이름이 **보라색**("선량한 캐릭터를 먼저 공격해 보라색 이름이 되었습니다")이 되고 60초 뒤 풀린다.
- [ ] 선량한 봇을 처치하면 성향치 −300, 이름이 **빨간색**(악명)이 된다. 정보 → PK 기록에 남는다.
- [ ] 악명 상태로 마을에 들어가면 **경비병** 이 쫓아와 공격한다. 상점 가격이 1.2배("악명 할증 x1.2")가 된다.
- [ ] 악명 상태로 죽으면 사망 창에 "…을(를) 떨어뜨렸습니다", 그 자리에 상자(바닥 아이템)가 생긴다. (QA) 확률을 1 로 두면 확실히 재현된다.
- [ ] 근처 봇이 그 상자를 주우러 가서 주우면 상자가 사라지고, 서버에서 그 봇의 `itemCount` 가 1 늘어난다.
- [ ] 그 봇을 처치하면 5단계 드랍 규칙으로 아이템을 되찾을 수 있다(GM 봇 전리품 확률 1 이면 확실).
- [ ] 봇이 먼저 때려 보라색이 된 봇을 처치하면 성향치가 깎이지 않는다.

## 6단계 QA 빌드

- [ ] QA APK 를 켜고 `control-cli ping` 이 `"ok":true` 로 답한다. Release APK 는 「붙지 못했습니다」로 답한다.
- [ ] `control-cli tree` 에 오브젝트 트리(`BootCanvas/LoginView/...`)가 보이고, `control-cli click LoginButton` 이 로그인 버튼을 누른다.
- [ ] HUD 의 **GM** 버튼으로 골드·아이템·레벨·순간이동·성향치를 바꾸면 화면과 서버가 함께 바뀐다. Release APK 에는 GM 버튼이 없다.
